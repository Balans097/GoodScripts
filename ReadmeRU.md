# 🐧 GoodScripts: Автоматизация работы с файлами в Linux

> Набор bash-скриптов для контекстного меню **Nautilus (GNOME Files)** и файлового менеджера **Double Commander**, превращающих рутинные операции с документами и медиа в один клик.

## 🚀 Как это улучшает работу в Linux?

GNOME придерживается философии минимализма: чистый интерфейс, отсутствие лишних окон, фокус на задачах. Однако встроенный файловый менеджер Nautilus намеренно не перегружен функциями конвертации или пакетной обработки. Эти скрипты закрывают этот пробел, сохраняя дух экосистемы. Для тех, кто предпочитает двухпанельные менеджеры, тот же набор доступен и для **Double Commander**.

- 🔹 **Интеграция без отрыва от контекста.** Всё доступно через стандартное контекстное меню (`ПКМ → Сценарии`) в Nautilus или через пользовательскую кнопку/команду в Double Commander. Не нужно искать программу или перетаскивать файлы в тяжёлые GUI-конвертеры.
- 🔹 **Фоновая работа + нативные уведомления.** Скрипты не создают модальных окон. Обработка идёт в фоне, а результат или ошибка сообщаются через стандартную систему уведомлений.
- 🔹 **Пакетность из коробки.** Выделяете папку или десятки файлов → запускаете скрипт → получаете готовый результат без ручного перебора.
- 🔹 **Полная приватность и контроль.** Все операции выполняются локально. Никаких облачных сервисов, телеметрии, водяных знаков или ограничений по размеру/количеству файлов.
- 🔹 **Прозрачность и лёгкость кастомизации.** Это обычный Bash + проверенные CLI-утилиты. Любой скрипт можно открыть, прочитать логику, изменить параметры или добавить поддержку новых форматов.
- 🔹 **Идеально для рабочих станций.** Экономит часы времени исследователям, авторам, разработчикам и всем, кто регулярно работает со сканами, документами, электронными книгами, логами и медиафайлами.

## 📁 Структура репозитория

```text
GoodScripts/
├── src_nautilus/           # Сценарии для меню «Сценарии» в Nautilus
├── src_double_commander/   # Сценарии для Double Commander (dc*.sh)
└── RetroShare/             # Вспомогательные скрипты сборки RetroShare (RPM для Fedora)
```

## 📦 Что внутри?

### 🗂️ Сценарии Nautilus (`src_nautilus/`)

У некоторых файлов в имени есть эмодзи-префикс — так они оказываются в начале меню Nautilus.

| Скрипт | Описание | Ключевые зависимости |
|--------|----------|----------------------|
| `🔍  dav-файлы → mp4-файлы.sh` | Конвертация видео с видеорегистраторов (`.dav`) в MP4 без пережатия | `ffmpeg` |
| `✅  djvu → pdf.sh` | Пакетное преобразование `.djvu`/`.djv` в PDF (поддержка файлов и папок) | `djvulibre` (`ddjvu`) |
| `💡  Документы → PDF.sh` | Объединение и конвертация документов (Word, Excel, ODT, TXT, EPUB, HTML и др.) в единый PDF | `libreoffice`, `poppler-utils` |
| `Изображения → PDF.sh` | Создание PDF из изображений с сохранением оригинальных размеров | `img2pdf` |
| `Изображения → PDF (A4).sh` | То же самое, но с автоматическим масштабированием под формат A4 | `img2pdf` |
| `📌  Объединить текстовые файлы в один файл.sh` | Рекурсивное слияние текстовых файлов/кода в один `.txt` с разделителями | `file` |
| `Разбить pdf-файл на фрагменты по 19 МБ.sh` | Разделение тяжёлых PDF на части ≤19 МБ (через `poppler-utils`) | `poppler-utils` |
| `Разбить pdf-файл на фрагменты по 19 МБ (qpdf).sh` | Более надёжная версия разбиения PDF через `qpdf` с верификацией реального размера | `qpdf` |

### 🖥️ Сценарии Double Commander (`src_double_commander/`)

| Скрипт | Назначение |
|--------|------------|
| `dcDav2mp4.sh` | Видео с регистраторов (`.dav`) → MP4 |
| `dcConvert2AAC.sh` | Конвертация аудио в AAC |
| `dcDir2mp3.sh` | Конвертация аудио из папки в MP3 |
| `dcDjvu2pdf.sh` | DjVu → PDF |
| `dcDjvu2pdf_ghostscript.sh` | DjVu → PDF, вариант на Ghostscript |
| `dcDocs2PDF.sh` | Документы → единый PDF |
| `dcImages2PDF.sh` | Изображения → PDF (оригинальные размеры) |
| `dcImages2PDF_A4.sh` | Изображения → PDF с масштабированием под A4 |
| `dcExtractPNG.sh` | Извлечение PNG-изображений |
| `dcEpub2docx.sh` / `dcEpub2odt.sh` | EPUB → DOCX / ODT |
| `dcFb2ToDocx.sh` / `dcFb2ToOdt.sh` | FB2 → DOCX / ODT |
| `dcMerge2txt.sh` | Слияние текстовых файлов в один `.txt` |
| `dcSplitPdfs.sh` | Разбиение больших PDF на части (poppler) |
| `dcSplitPdfs_qpdf.sh` | Разбиение больших PDF на части (qpdf) |

> ℹ️ Точные аргументы и дополнительные зависимости каждого скрипта описаны в комментариях в начале файла.

### 📡 Вспомогательные скрипты RetroShare (`RetroShare/`)

`MakeRetroShareRPM.sh` собирает RPM-пакет RetroShare для Fedora (сборка на Qt6 из исходников upstream-репозитория). Вложенная папка `retroshare/` — копия оригинального проекта с его собственными скриптами сборки и тестирования; они принадлежат авторам RetroShare и не входят в данный набор.

## 🛠️ Установка

1. **Склонируйте репозиторий:**
   ```bash
   git clone https://github.com/Balans097/GoodScripts.git
   cd GoodScripts
   ```

### Nautilus

2. **Скопируйте сценарии в директорию Nautilus:**
   ```bash
   mkdir -p ~/.local/share/nautilus/scripts
   cp src_nautilus/*.sh ~/.local/share/nautilus/scripts/
   ```

3. **Сделайте сценарии исполняемыми:**
   ```bash
   chmod +x ~/.local/share/nautilus/scripts/*.sh
   ```

4. **Перезапустите Nautilus:**
   ```bash
   nautilus -q
   ```

### Double Commander

1. Скопируйте сценарии в удобную папку и сделайте их исполняемыми:
   ```bash
   mkdir -p ~/.config/doublecmd/scripts
   cp src_double_commander/*.sh ~/.config/doublecmd/scripts/
   chmod +x ~/.config/doublecmd/scripts/*.sh
   ```
2. В Double Commander откройте **Настройки → Панель инструментов** (или **Действия / Горячие клавиши**), добавьте **внешнюю команду** с путём к нужному скрипту и передайте выделенные файлы параметром (например, `%LU` или `%L` — зависит от скрипта, см. его заголовок).

## 📦 Зависимости

Скрипты используют стандартные CLI-утилиты. Установите нужные пакеты для вашего дистрибутива:

**Fedora / RHEL / AlmaLinux / Rocky:**
```bash
sudo dnf install ffmpeg djvulibre poppler-utils libreoffice img2pdf qpdf ghostscript file libnotify
```

**Ubuntu / Debian / Linux Mint / Pop!_OS:**
```bash
sudo apt install ffmpeg djvulibre-bin poppler-utils libreoffice img2pdf qpdf ghostscript file libnotify-bin
```

**Arch Linux / Manjaro / EndeavourOS:**
```bash
sudo pacman -S ffmpeg djvulibre poppler libreoffice-fresh img2pdf qpdf ghostscript file libnotify
```

> ⚠️ Зависимости нужны **не все сразу**. Каждый скрипт во время работы проверяет наличие своих инструментов и показывает понятное уведомление, если чего-то не хватает.

## 🖱️ Использование

**Nautilus**
1. Выделите один или несколько файлов/папок в Nautilus.
2. ПКМ → `Сценарии` → выберите нужный скрипт.
3. Дождитесь уведомления в правом верхнем углу.

**Double Commander**
1. Выделите файлы/папки в активной панели.
2. Нажмите кнопку на панели инструментов или горячую клавишу, привязанную к скрипту.

Результат создаётся в той же папке (или рядом с первым выделенным объектом).

✅ **Безопасность данных:** скрипты **никогда не перезаписывают** исходные файлы. Новые файлы получают префиксы (`merged_`, `_part_X`) или другое расширение.

## 🔧 Настройка и решение проблем

- Пути и параметры настраиваются в начале каждого скрипта (например, `OUTPUT_PREFIX`, `SUPPORTED_EXT` или размеры страниц).
- Для отладки добавьте `set -x` в начало скрипта или загляните в логи в `/tmp/` (их ведут скрипты разбиения через `qpdf`).
- Полностью поддерживаются пути с пробелами и не-ASCII символами (кириллица и др.).
- При отсутствии зависимостей появляется уведомление с подсказкой по установке.
- Если скрипт не появился в меню Nautilus, проверьте, что он исполняемый, и перезапустите Nautilus (`nautilus -q`).
